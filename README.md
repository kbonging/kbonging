# 안녕하세요, 백엔드 개발자 김봉중입니다.

Java 기반 웹 서비스의 운영·개선 업무를 경험하며,  
요구사항을 코드와 데이터 흐름으로 구체화하고 안정적으로 반영하는 백엔드 개발자입니다.

관리자 기능, 교육·회원 데이터, 인증, 이력 관리, 통계 기능을 중심으로  
기존 시스템을 분석하고 유지보수 가능한 방식으로 개선하는 데 집중해왔습니다.

## 🛠 Tech Stack

- **Backend**: Java, Spring Framework, eGovFrame
- **Database**: MySQL, Microsoft SQL Server, SQL
- **Web**: JSP, JavaScript, jQuery, HTML, CSS
- **Tools**: Git, SVN, Maven, Tomcat, Eclipse, IntelliJ IDEA

## 💼 주요 경험

- 공공기관 관리자 시스템에서 위원회·위원 관리 등 관리자 기능 개발
- 회원·교육 운영, 검색·엑셀 다운로드, 상태 이력 유지보수 및 개선
- Java·JSP·SQL 기반의 Controller, Service, SQL Mapper, DB 연동 기능 개발
- 사용자 정보 조회·수정 과정의 인증·인가 검증을 보완하고 웹 보안 취약점 조치
- 회원가입 및 비밀번호 검증 로직을 개선해 데이터 검증 안정성 강화
- 웹 분석 도구 환경 설정 및 회원 유형·국가·내부 검색어 기반의 이용 데이터 수집 지원
- 기존 코드와 SQL 흐름을 분석해 운영 이슈 및 데이터 오류 원인 파악·개선
